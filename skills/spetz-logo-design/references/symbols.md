# ספריית הסמלים

סמלי קו מקוריים בתיבה של 100 על 100. עורכים או מוסיפים בקובץ `scripts/symbols.py`.

| סמל | מתאים ל |
|---|---|
| scales | משפט, חוק, גישור |
| document | מסמכים, חוזים, ניהול תיקים |
| shield | אבטחה, ביטוח, הגנה |
| people | קהילה, ייעוץ, משאבי אנוש |
| book, education | חינוך, הוצאה לאור, קורסים |
| health, heart | בריאות, טיפול, התנדבות |
| leaf, tree, drop, sun | טבע, קיימות, ניקיון |
| coffee | קפה, מסעדות, מאפים |
| code, bolt, gear | טכנולוגיה, אנרגיה, תעשייה |
| house, building, key | נדל"ן, בנייה, ניהול נכסים |
| chart | פיננסים, חשבונאות, נתונים |
| camera | צילום, וידאו, סטודיו |
| chat | תקשורת, שיווק, תמיכה |
| shop | חנויות, מסחר |
| compass, mountain, wave | הדרכה, טיולים, ים |
| star, check | איכות, אישור, שירות מצטיין |

## הוספת סמל

1. מציירים קווים פשוטים בתיבה של 100 על 100, בלי מילוי, ובעובי קו אחד (6).
2. מוסיפים ערך חדש ל-`SYMBOLS` ברשימת נתיבים.
3. מוסיפים אותו להצעות ב-`INDUSTRIES` אם הוא מתאים לתחום.
4. מריצים `python tools/smoke_test.py`. הבדיקה מוודאת שהסמל מפיק SVG תקין.

אסור לשחזר צורות שמזוהות עם מותג מסוים.
