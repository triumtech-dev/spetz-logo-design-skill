# עיצוב לוגו לעסק

שירות מטעם Trium Technology.

## התהליך

1. **ראיון.** שואלים את השאלות שב-`references/interview.md`, שאלה אחת בכל פעם, בעברית. לא ממשיכים בלי שם עסק ותחום.
2. **כיוון.** מציעים שני או שלושה כיווני סגנון עם נימוק של משפט אחד לכל כיוון, ומבקשים בחירה. הכללים ב-`references/principles.md`.
3. **הפקה.** מריצים:

```bash
python skills/spetz-logo-design/scripts/make_logo.py --name "שם העסק" --color "#2563eb" --style rounded --out out
```

   להוספת PNG (נדרש Chrome או Edge) מוסיפים `--png`. נוצרים חמישה קבצי SVG: `horizontal`, `stacked`, `wordmark`, `horizontal-on-dark`, `mono-black`.
4. **שיפור.** מבקשים משוב, משנים צבע, סגנון או שם, ומריצים שוב. הגרסה האחרונה נשמרת בתיקייה נפרדת.

## כללים

- לא מעתיקים לוגו של מותג קיים ולא מדמים אותו. אם המשתמש מבקש "כמו" מותג מסוים, מסבירים שאפשר רק לקחת השראה כללית בסגנון.
- הפלט הוא נקודת פתיחה. לשימוש מסחרי מומלץ לבדוק זמינות שם וסימן מסחרי לפני הדפסה.
- כל הטקסט למשתמש בעברית. בלי הבטחות על תוצאה עסקית.
- הקבצים נוצרים מקומית. לא שולחים את פרטי העסק לשירות חיצוני.
