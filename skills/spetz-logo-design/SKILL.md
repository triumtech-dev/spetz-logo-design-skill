# עיצוב לוגו לעסק

שירות מטעם Trium Technology. הפלט הוא סט לוגו מוכן לשימוש ראשוני, ונקודת פתיחה טובה למעצב.

## התהליך

1. **ראיון.** שאלה אחת בכל פעם, בעברית, לפי `references/interview.md`. לא ממשיכים בלי שם עסק ותחום. אם המשתמש כבר נתן תשובה, לא שואלים שוב.
2. **הצעות.** מריצים הצעה אוטומטית לפי התחום:

```bash
python skills/spetz-logo-design/scripts/make_logo.py --suggest "עורך דין"
```

   מוצגים סמלים, צבע ראשי ומשני, פונט וסגנון. מציגים למשתמש שניים או שלושה כיוונים עם נימוק של משפט לכל אחד. רשימת הסמלים המלאה: `--list-symbols`. עקרונות הבחירה ב-`references/principles.md`.
3. **הפקה.** מריצים כיוון אחד לכל תיקייה, עם תצוגה מקדימה להשוואה:

```bash
python skills/spetz-logo-design/scripts/make_logo.py --name "שם העסק" --tagline "שורת משנה" \
  --symbol scales --color "#1e3a5f" --accent "#b8893a" --font frank --out out/a --png --preview
```

   נוצרים: `horizontal`, `stacked`, `wordmark`, `icon`, `app-icon`, `horizontal-on-dark`, `mono-black`, `mono-white`, וקובץ `preview.html` להשוואה. `--png` דורש Chrome או Edge. בלי סמל (`--symbol monogram`, ברירת המחדל) נוצרת מונוגרמה מאות הפתיחה בצורה לבחירה (`--style`).
4. **בדיקה.** לפני שמציגים: לבדוק שהלוגו קריא בגודל 32 פיקסלים, על רקע כהה ובשחור, ושהסדר נכון לשם בעברית, בלטינית ובשם מעורב.
5. **שיפור.** מקבלים משוב ומשנים סמל, צבע, פונט או שם. כל גרסה נשמרת בתיקייה נפרדת. מסיימים רק אחרי אישור המשתמש על כיוון אחד.

## כללים

- הסמלים בספרייה מקוריים וגנריים. לא מעתיקים ולא מדמים לוגו של מותג קיים. אם מבקשים "כמו" מותג מסוים, לוקחים השראה כללית בסגנון בלבד.
- הפונטים מוגדרים כרשימת גיבוי. אם הפונט לא מותקן אצל המשתמש, יוצג פונט חלופי. להדפסה ולשילוט ממליצים להמיר את הטקסט לקווים (outlines) בתוכנת עריכה, ולבדוק רישיון פונט לשימוש מסחרי.
- רוחב הטקסט מוערך ולא נמדד. בשמות ארוכים מאוד בודקים בתצוגה מקדימה ומתקנים ידנית אם צריך.
- הפלט הוא נקודת פתיחה. לשימוש מסחרי מומלץ לבדוק זמינות שם וסימן מסחרי.
- כל הטקסט למשתמש בעברית. בלי הבטחות על תוצאה עסקית.
- הקבצים נוצרים מקומית. לא שולחים את פרטי העסק לשירות חיצוני.
